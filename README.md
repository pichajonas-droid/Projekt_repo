# Seznam členů
- Jonáš Pícha : GitHub - @pichajonas-droid

# Zadání
Skript v pythonu, který zpracuje prostřednictvím RTKlib nasbíraná RINEX data a analyzuje přesnost výsledných souřadnic pomocí grafů.

- spočítat souřadnice
- vyfiltrovat FIXované epochy
- odchylky souřadnic znázornit v grafu
